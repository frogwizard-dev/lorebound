# Lorebound quest reports

Paste the codes from Lorebound's "Share new quests" box here, one `.txt` file per report (any name).
`make_lore.py` reads every `LM1^...` line and adds quests its other sources haven't got; then sync and
release Lorebound_Data as usual. Lines for quests already in the list are skipped, so pasting the same
report twice does no harm.
